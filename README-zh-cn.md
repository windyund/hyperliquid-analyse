为什么"赚得多 ≠ 值得跟"
Hyperliquid 排行榜只按已实现盈亏排名，但榜上前排其实混着三种人：
- 🎰 一把赌赢的 — 重仓赌对一次、赚得夸张，但没有长期稳定的交易能力，下一把可能就还回去；
- ♻️ 马丁画像的 — 靠大资金硬扛、不断摊平成本，账面好看直到爆仓那天；这种大户有资金支撑，普通人跟不起也扛不住，没有可跟性；
- ✅ 真正值得跟的 — 收益没那么夸张，但回撤小、交易时间长、风格稳、夏普率高。

问题是：排行榜那一个数字，根本分不出这三种人。这就是 HyperIntel 做的事。

三大差异化
1. 筛真高手，不是看余额 — 每个鲸鱼按 MTM（盯市）表现、回撤、夏普率、90 天以上胜率打分，不是看漂亮的已实现 PnL。
2. 风险信号直接摆出来 — 马丁、刷量、做市商钱包自动标红旗，不藏在一个排名数字后面。
3. 可复制性量化 — 对方赚的 ≠ 你能赚的。大资金硬扛的、信号太慢跟不上的，都会被标出来"跟不了"，并估算跟随者在延迟/滑点后实际能捕获多少。
